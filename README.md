# Heart Attack Risk Prediction


## Project Overview

This project uses supervised machine learning to predict the risk of myocardial infarction (heart attack) from patient health data.

## Objective

To develop and evaluate supervised machine learning models for predicting heart attack risk using the given dataset.

## Dataset

The dataset contains patient health and clinical attributes such as:

- Age
- Sex
- Chest pain type
- Resting blood pressure
- Cholesterol
- Fasting blood sugar
- Resting ECG
- Maximum heart rate
- Exercise-induced angina
- ST depression
- Slope
- Number of major vessels
- Thallium

## Machine Learning

The supervised learning workflow includes:

1. Data loading and exploration
2. Data preprocessing
3. Feature scaling
4. One-hot encoding of categorical features
5. Train-validation-test splitting
6. Logistic Regression baseline
7. Additional supervised classification models
8. Model evaluation
9. Confusion matrix and ROC curve analysis
10. Model comparison
